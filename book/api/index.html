Named forms¶

named_form(db, name; create = false, value = nothing)  # look up, or create, by name
name_form!(db, name, vf::VolatileForm)                 # register vf under name (overwrites)
named_forms(db)                                        # the whole table, as a PDict

name may be a Symbol or a String; both refer to the same form. For named_form, create is false (raise if absent), true (create; raise if present), or nothing (return nothing if absent). value is the new form’s initial value, used only when creating; it may be a Form, something a Form can be made from, nothing (an empty form), or an existing VolatileForm (which is aliased rather than copied). Registering or renaming is transactional: it joins the caller’s transaction, or runs in one of its own.

Air re-exports¶

AirDB builds on Air’s transaction system, which you use directly:

using Air                  # @tx, tx, Volatile, Actor, send, ...

Errors¶

errorraised when
ArgumentErrora bad config, a non-key index, no volatile on a setindex! path, indexing a leaf
KeyErrora missing map key
BoundsErrora missing sequence position, or an out-of-range append
FormNotFoundloading a form whose id is not in the database
DatabaseErrora database operation failed and the policy gave up
ExternErrora form holds an extern type that is not registered
ExternTombstonean extern was written as a tombstone (:abandoned/:expired)
