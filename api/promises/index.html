The single-assignment form, its commit state, and the lookup API.

PromiseForm¶

PromiseForm

A Form backed by an Air Promise{Form}. A promise is delivered once; a form that holds one stores the link "~<uuid>", whether the promise is pending, delivered, or failed, and the promise always has a row to hold its state, so its identity and outcome survive a round trip.

Create one with PromiseForm(db); deliver it with put!(pf, value); retrieve an existing one with get_promise.

PromiseForm(db; pending_commit = false, metadata = nothing) -> PromiseForm

Create an undelivered promise form. Settle it with put!(pf, value) or fail!(pf, error); the outcome is persisted when the settling transaction commits (or immediately, outside a transaction). metadata is the owner/ACL metadata blob.

pending_commit = true marks a promise created inside a transaction that has not committed: reading it raises UncommittedPromise until mark_committed!, and mark_aborted! makes every read raise AbortedPromise. Settling a pending promise is allowed.

get_promise¶

get_promise(db::AbstractDatabase, id::UUID) -> PromiseForm

The promise form with the given id, cached like get_form.

UncommittedPromise¶

UncommittedPromise

Raised when a promise created inside a transaction is read before that transaction commits. See PromiseForm.

AbortedPromise¶

AbortedPromise

Raised when a promise whose creating transaction aborted is read or delivered.

mark_pending_commit!¶

mark_pending_commit!(pf::PromiseForm) -> PromiseForm

Marks the promise as created by a transaction that has not committed yet, so reading it raises UncommittedPromise.

mark_pending_commit!(sf::StreamForm) -> StreamForm

Marks the stream as created by a transaction that has not committed yet, so read-like operations raise UncommittedStream.

mark_committed!¶

mark_committed!(pf::PromiseForm) -> PromiseForm

Marks the promise’s creating transaction as committed: the promise becomes :live and readable.

mark_committed!(sf::StreamForm) -> StreamForm

Marks the stream’s creating transaction as committed: the stream becomes :live.

mark_aborted!¶

mark_aborted!(pf::PromiseForm) -> PromiseForm

Marks the promise’s creating transaction as aborted: every read or settlement raises AbortedPromise.

mark_aborted!(sf::StreamForm) -> StreamForm

Marks the stream’s creating transaction as aborted: every operation raises AbortedStream.
