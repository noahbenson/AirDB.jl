The value types: scalar and container forms, the builders that create them, and the helpers that classify a leaf.

Form¶

Form

The abstract supertype of every form: FormScalar (a bare leaf), FormContainer (a sequence and a map), and VolatileForm (a form that persists itself). The concrete kinds are gathered in FormNode.

Form(x::FormLeaf) -> FormScalar
Form(seq, map) -> FormContainer
form(seqargs...; mapargs...) -> FormContainer

Form(x) for a leaf builds a scalar form, and Form(seq, map) builds a container from collections. form(...) is the general builder: its positional arguments become the sequence and its keyword arguments the map, each converted the way to_form does.

FormScalar¶

FormScalar(value)

A form holding just a leaf (see FormLeaf): a string, symbol, Bool, Nothing, or one of the numeric tower’s value types. Form(x) for a leaf x builds one, and indexing a container wraps a leaf into one, so every value read out of a form is a form. Use value to get the leaf back.

FormContainer¶

FormContainer(seq, map)

A form holding a sequence of positional values (seq) and a map of symbol-keyed values (map), each a FormValue. Build one with form, to_form, or from prepared collections.

FormLeaf¶

FormLeaf

The scalar values a form can hold: String, Symbol, Bool, Nothing, and the numeric tower wherever it is a value type — Int64, BigInt, Float64, BigFloat, Rational{Int64}, Rational{BigInt}, ComplexF64 and Complex{BigFloat}. A FormScalar wraps one; a FormContainer holds forms and leaves. Narrower scalar types are converted to one of these where the conversion is exact; see to_form.

FormValue¶

FormValue

What a FormContainer holds directly: a Form or a FormLeaf.

form¶

form(seqargs...; mapargs...) -> FormContainer

Build a container from its arguments: the positional arguments become the sequence and the keyword arguments the map, each converted the way to_form does.

Examples¶

form("widget", 1, meta = form(name = "abc"))

to_form¶

to_form(x) -> Form

x as a form: a form is returned as it is, a leaf becomes a FormScalar, and a Vector/PVector or Dict/PDict becomes a FormContainer. Anything else raises.

value¶

value(fs::FormScalar)
value(fe::FormExtern)

The leaf a scalar form wraps, or the data an extern form wraps (loading it from the database first if it was loaded rather than constructed).

is_form_representable¶

is_form_representable(x) -> Bool

Whether to_form(x) can represent x without raising. It mirrors the conversion rules exactly:

  • any Form, FormLeaf, Bool, Symbol, String, Char, Integer, Rational, Float16/Float32/Float64/BigFloat, or Irrational;

  • a Complex whose parts are exactly Float64 or exactly BigFloat (so complex(1//2, 3//2) is representable, but complex(1//3, 0) is not);

  • an AbstractAirExtern whose type is registered;

  • recursively, an AbstractVector of representable values, or an AbstractDict whose keys are symbols/strings/chars and whose values are representable.

It is a pre-check only: to_form itself is unchanged and still raises an ArgumentError for a value it cannot represent.

iskeyword¶

iskeyword(f) -> Bool

Whether f is a keyword — a symbol scalar form whose name begins with :, such as Form(Symbol(":abc")). Any other form is not a keyword. See iswildcard.

iswildcard¶

iswildcard(f) -> Bool

Whether f is a wildcard — a symbol scalar form whose name begins with ?, such as Form(Symbol("?abc")). Any other form is not a wildcard. See iskeyword.
