The FIFO form, its commit state, and the lookup API.

StreamForm¶

StreamForm

A Form backed by an Air Stream{Form}: a FIFO of forms that supports blocking put!/take, an optional bound, timeouts, and close. Its contents are persisted, and it loads lazily by id.

Create one with StreamForm(db; maxsize, metadata); retrieve an existing one with get_stream. In JSON a stream is written "&<uuid>".

StreamForm(db; maxsize = nothing, pending_commit = false,
           metadata = nothing) -> StreamForm

Create a stream form and register its (empty) row for writing. maxsize bounds the number of queued forms (nothing leaves it unbounded). Send and receive with put!(sf, value) and take(sf); both accept timeout and token keywords, and close(sf) ends the stream. metadata is the owner/ACL metadata blob.

pending_commit = true marks a stream created inside a transaction that has not committed: read-like operations raise UncommittedStream until mark_committed!, and mark_aborted! makes every operation raise AbortedStream. Writing to a pending stream is allowed.

get_stream¶

get_stream(db::AbstractDatabase, id::UUID) -> StreamForm

The stream form with the given id, cached like get_form.

UncommittedStream¶

UncommittedStream

Raised when a stream created inside a transaction is used before that transaction commits. See StreamForm.

AbortedStream¶

AbortedStream

Raised when a stream whose creating transaction aborted is used.
