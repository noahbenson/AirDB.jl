## ActorForm

```julia
ActorForm
```

A [`Form`](forms.md#api-form) backed by an Air `Actor{Form}`: its value is updated by sending
functions to it, and every update is written to the database. Most actors are
orderly workers, and this one persists each value it takes.

Create one with `ActorForm(db, args...; kwargs...)` or
`ActorForm(db, form::Form; history = true)`; retrieve an existing one with
[`get_actor`](#api-get-actor). In JSON an actor is written `"!<uuid>"`.


```julia
ActorForm(db, form::Form; history = true, metadata = nothing) -> ActorForm
ActorForm(db, args...; history = true, metadata = nothing, kwargs...) -> ActorForm
```

Create an actor form and register its initial value for writing. Send functions
to it with `send(af) do value ... end`; each new value is persisted. `history`
is fixed for the actor's life: `true` appends a history row per update, `false`
overwrites the current row. `metadata` is the owner/ACL metadata blob.

## get_actor

```julia
get_actor(db::AbstractDatabase, id::UUID) -> ActorForm
```

The actor form with the given id, cached like [`get_form`](volatile-forms.md#api-get-form).
