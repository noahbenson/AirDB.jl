The value types: scalar and container forms, the builders that create
them, and the helpers that classify a leaf.

(api-form)=
## Form

```julia
Form
```

The abstract supertype of every form: [`FormScalar`](#api-formscalar) (a bare leaf),
[`FormContainer`](#api-formcontainer) (a sequence and a map), and [`VolatileForm`](volatile-forms.md#api-volatileform) (a form
that persists itself). The concrete kinds are gathered in `FormNode`.


```julia
Form(x::FormLeaf) -> FormScalar
Form(seq, map) -> FormContainer
form(seqargs...; mapargs...) -> FormContainer
```

`Form(x)` for a leaf builds a scalar form, and `Form(seq, map)` builds a container
from collections. `form(...)` is the general builder: its positional arguments
become the sequence and its keyword arguments the map, each converted the way
[`to_form`](#api-to-form) does.


(api-formscalar)=
## FormScalar

```julia
FormScalar(value)
```

A form holding just a leaf (see [`FormLeaf`](#api-formleaf)): a string, symbol, `Bool`,
`Nothing`, or one of the numeric tower's value types. `Form(x)` for a leaf `x`
builds one, and indexing a container wraps a leaf into one, so every value read
out of a form is a form. Use [`value`](#api-value) to get the leaf back.


(api-formcontainer)=
## FormContainer

```julia
FormContainer(seq, map)
```

A form holding a sequence of positional values (`seq`) and a map of symbol-keyed
values (`map`), each a [`FormValue`](#api-formvalue). Build one with [`form`](#api-form),
[`to_form`](#api-to-form), or from prepared collections.


(api-formleaf)=
## FormLeaf

```julia
FormLeaf
```

The scalar values a form can hold: `String`, `Symbol`, `Bool`, `Nothing`, and
the numeric tower wherever it is a value type —
`Int64`, `BigInt`, `Float64`, `BigFloat`, `Rational{Int64}`,
`Rational{BigInt}`, `ComplexF64` and `Complex{BigFloat}`. A [`FormScalar`](#api-formscalar)
wraps one; a [`FormContainer`](#api-formcontainer) holds forms and leaves. Narrower scalar
types are converted to one of these where the conversion is exact; see
[`to_form`](#api-to-form).


(api-formvalue)=
## FormValue

```julia
FormValue
```

What a [`FormContainer`](#api-formcontainer) holds directly: a [`Form`](#api-form) or a
[`FormLeaf`](#api-formleaf).


(api-form)=
## form

```julia
form(seqargs...; mapargs...) -> FormContainer
```

Build a container from its arguments: the positional arguments become the
sequence and the keyword arguments the map, each converted the way
[`to_form`](#api-to-form) does.

### Examples
```julia
form("widget", 1, meta = form(name = "abc"))
```


(api-to-form)=
## to_form

```julia
to_form(x) -> Form
```

`x` as a form: a form is returned as it is, a leaf becomes a
[`FormScalar`](#api-formscalar), and a `Vector`/`PVector` or `Dict`/`PDict` becomes a
[`FormContainer`](#api-formcontainer). Anything else raises.


(api-value)=
## value

```julia
value(fs::FormScalar)
value(fe::FormExtern)
```

The leaf a scalar form wraps, or the data an extern form wraps (loading it from
the database first if it was loaded rather than constructed).


(api-is-form-representable)=
## is_form_representable

```julia
is_form_representable(x) -> Bool
```

Whether [`to_form(x)`](#api-to-form) can represent `x` without raising. It
mirrors the conversion rules exactly:

- any [`Form`](#api-form), `FormLeaf`, `Bool`, `Symbol`, `String`, `Char`, `Integer`,
  `Rational`, `Float16`/`Float32`/`Float64`/`BigFloat`, or `Irrational`;
- a `Complex` whose parts are exactly `Float64` or exactly `BigFloat` (so
  `complex(1//2, 3//2)` is representable, but `complex(1//3, 0)` is not);
- an [`AbstractAirExtern`](externs.md#api-abstractairextern) whose type is registered;
- recursively, an `AbstractVector` of representable values, or an
  `AbstractDict` whose keys are symbols/strings/chars and whose values are
  representable.

It is a pre-check only: `to_form` itself is unchanged and still raises an
`ArgumentError` for a value it cannot represent.


(api-iskeyword)=
## iskeyword

```julia
iskeyword(f) -> Bool
```

Whether `f` is a keyword — a symbol scalar form whose name begins with `:`, such
as `Form(Symbol(":abc"))`. Any other form is not a keyword. See
[`iswildcard`](#api-iswildcard).


(api-iswildcard)=
## iswildcard

```julia
iswildcard(f) -> Bool
```

Whether `f` is a wildcard — a symbol scalar form whose name begins with `?`, such
as `Form(Symbol("?abc"))`. Any other form is not a wildcard. See
[`iskeyword`](#api-iskeyword).
