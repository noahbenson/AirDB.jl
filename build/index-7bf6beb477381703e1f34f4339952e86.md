## Errors

| error | when |
| --- | --- |
| `DatabaseError` | a database operation failed; under `:abort` it fails the whole database |
| `FormNotFound` | a form id is not in the database |
| `ExternError` | an extern operation used a dead or unregistered extern, or a registration is inconsistent |
| `FailedObjectError` | loading an object whose write was quarantined |
